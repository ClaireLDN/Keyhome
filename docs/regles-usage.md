# Règles d'usage

- Utilisez les tokens (`var(--color-*)`, `var(--radius-*)`) plutôt que des valeurs en dur.
- Chaque composant doit afficher ses états : défaut, survol, focus, désactivé, erreur.
- Les données affichées sont fictives. Ne pas utiliser de données réelles d'annonces.
- Pas de reprise de l'identité, des photos ou du code d'un site existant.
